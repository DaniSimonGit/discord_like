===============================================================================
                       MANUAL DE USUARIO Y DOCUMENTACIÓN
                        PROYECTO: DISCORD_LIKE (ELECTRON)
===============================================================================

1. DESCRIPCIÓN DEL PROYECTO
-------------------------------------------------------------------------------
"Discord_like" es una aplicación de escritorio multiplataforma desarrollada con 
Electron, Node.js, Express, Socket.io y PeerJS (WebRTC). Réplica ligera y privada 
de Discord orientada a la comunicación por texto y voz en tiempo real dentro de 
redes locales (LAN) o redes privadas virtuales (VPN).


2. REQUISITOS DEL SISTEMA
-------------------------------------------------------------------------------
- Sistema Operativo: Windows 10/11, Linux o macOS.
- Para desarrollo: Node.js (v18 o superior) y npm.
- Permisos de red en el Firewall de Windows para Node.js/Electron.


3. CÓMO EJECUTAR LA APLICACIÓN EN DESARROLLO
-------------------------------------------------------------------------------
Abre una terminal de comandos en la carpeta raíz del proyecto y ejecuta:

    npm start

Este comando compila los activos e inicia Electron Forge (`electron-forge start`).

Si actualizas la librería del filtro de ruido (`@sapphi-red/web-noise-suppressor`),
ejecuta después este comando para copiar la nueva versión a `public/vendor/rnnoise/`:

    npm run vendor:rnnoise


4. MODOS DE USO Y CONFIGURACIÓN DE RED
-------------------------------------------------------------------------------
Al iniciar la aplicación por primera vez se presenta la pantalla de elección:

A) 👑 HOSTEAR SERVIDOR (Ser el Host)
   - Al pulsar "Hostear Servidor" eliges una CONTRASEÑA (mínimo 4 caracteres).
     Sin ella nadie puede entrar al chat ni a la voz: pásasela a tus amigos
     junto con la IP, por un canal privado.
   - El proceso principal de Electron arranca el 
     servidor Node.js backend (`server.js`) escuchando en el puerto 3000 (HTTP/Socket.io) 
     y el servidor de señalización de voz PeerJS en el puerto 3001.
   - La aplicación detecta automáticamente todas las direcciones IP de tu equipo 
     (Wi-Fi, Ethernet, VPN, etc.) y las muestra en la barra lateral con un 
     botón 📋 para copiarlas con un solo clic.

B) 🤝 UNIRSE AL SERVIDOR (Ser Cliente)
   - Introduce la IP del Host (por ejemplo `192.168.1.50`) y pulsa
     "Guardar y Conectar".
   - En la pantalla de login escribe tu nombre y la contraseña del Host. La app
     la recuerda para la próxima vez.
   - La app se conectará al servidor del Host sin necesidad de ejecutar un backend local.


5. GUÍA PARA CONECTARSE DESDE DISTINTOS ORDENADORES
-------------------------------------------------------------------------------
- OPCIÓN 1: Misma casa / Red Local (LAN)
  El Host pulsa "Hostear Servidor" y comparte su IP local (ej. 192.168.1.35).
  Los demás eligen "Unirse al Servidor" y colocan esa IP.

- OPCIÓN 2: Por Internet sin abrir puertos (VPN)
  Todos los usuarios se unen a una misma red privada virtual (VPN).
  El Host comparte la IP que le asigna la VPN (aparece en el banner de IPs).
  Los demás se conectan colocando esa IP.
  - Windows suele marcar las redes virtuales como "Públicas" y bloquear las
    conexiones entrantes. En el Host, permite la app también en redes públicas
    cuando salga el aviso del Firewall, o marca la red como "Privada"
    (Configuración > Red e Internet).
  - Si la IP del Host cambia, los demás tendrán que pulsar "Cancelar" o 🌐 e
    introducir la nueva.

- OPCIÓN 3: Por Internet Directo (Apertura de Puertos)
  El Host redirige en su Router los puertos 3000 (TCP) y 3001 (TCP) hacia la IP
  de su PC. Los demás se conectan usando la IP pública del Host.
  - Así el servidor queda accesible desde todo internet: usa una contraseña
    larga y difícil de adivinar (tras 5 intentos fallidos la IP queda bloqueada
    1 minuto, pero una contraseña débil se acaba adivinando).
  - Si la IP del router no coincide con la que muestran webs tipo "cuál es mi
    IP", tu operadora usa CGNAT y abrir puertos no funcionará: usa la Opción 2.
  - La IP pública suele cambiar cada cierto tiempo; habrá que pasar la nueva.
  - La voz va directa entre los PCs. En redes muy restrictivas (datos móviles,
    redes de empresa) puede no conectar aunque el chat funcione.


6. FUNCIONALIDADES DEL CHAT Y DE VOZ
-------------------------------------------------------------------------------
- SALAS DE TEXTO: Canales `#General`, `#Juegos` y `#Música`.
- LISTA DE CONECTADOS: Panel derecho con contadores de usuarios en tiempo real.
- CANAL DE VOZ WEBRTC: Transmisión de voz P2P de baja latencia.
- INDICADOR DE VOZ: Halo verde brillante alrededor del avatar al hablar.
- CONTROLES DE AUDIO: 
  - 📞 Unirse / 📵 Desconectar Voz
  - 🎤 Mutear Micrófono
  - 🎧 Ensordecer (Mutear audio entrante)
  - ⚙️ Ajustes de entrada/salida de audio
  - 🎙️ Probar micrófono (en ⚙️ Ajustes): te escuchas a ti mismo tal y como te
    oirán los demás. Úsalo con cascos; es normal un ligero eco por el retardo.
- FILTRO DE RUIDO (RNNoise): elimina el ruido de fondo constante (ventiladores,
  zumbidos) y atenúa teclado y golpes. Los ruidos fuertes y cortos, como las
  palmadas, se reducen pero pueden seguir oyéndose.
- 🚪 SALIR: Botón en la cabecera del chat para cerrar sesión limpiamente.
- 🌐 SERVIDORES: Botón en la barra de audio para cambiar de IP o modo de servidor.


7. CÓMO GENERAR EL EJECUTABLE COMPILADO (.EXE)
-------------------------------------------------------------------------------
Para compartir la aplicación lista para usar (sin necesidad de VS Code o Node.js 
en los ordenadores de tus amigos):

1. Ejecuta en la terminal:
   
       npm run make

2. Se generará la carpeta `out/make/zip/win32/x64/` conteniendo la aplicación 
   empaquetada en un archivo `.zip`.
3. Tus amigos solo tendrán que descomprimir el archivo y hacer doble clic sobre 
   `discord_like.exe`.


8. RESOLUCIÓN DE PROBLEMAS HABITUALES
-------------------------------------------------------------------------------
- NO SE ESCUCHA EL AUDIO / NO FUNCIONA EL MICRÓFONO:
  Verifica los permisos del micrófono en el sistema operativo y el dispositivo
  elegido en ⚙️ Ajustes.
- NO SE CONECTA DESDE OTRO PC:
  El Firewall de Windows del Host debe permitir conexiones entrantes en el
  puerto 3000 (chat) y en el 3001 (voz). Si solo está abierto el 3000, el chat
  funcionará pero la voz no.
- EL CHAT FUNCIONA PERO LA VOZ NO DESDE UN NAVEGADOR:
  Hay que usar la aplicación de escritorio. Si se abre `http://<IP_DEL_HOST>:3000`
  en un navegador web, éste bloquea el micrófono por no ser un origen seguro (HTTPS).
- ME OIGO CON ECO EN LA PRUEBA DE MICRÓFONO:
  Un eco ligero y único es normal: el filtro añade un pequeño retardo y tu voz
  llega a los cascos un poco después de que la oigas tú mismo. En la llamada
  no ocurre. Si el eco se repite o hay pitidos, estás usando altavoces: la
  prueba debe hacerse con cascos.
- "CONTRASEÑA INCORRECTA" / "DEMASIADOS INTENTOS":
  Pide la contraseña al Host. Tras 5 fallos seguidos hay que esperar 1 minuto.
  Si el Host cambió la contraseña, escribe la nueva en el login.
- "EL NOMBRE YA ESTÁ EN USO":
  Ya hay alguien conectado con ese nombre (sin distinguir mayúsculas). Elige otro.
- "VAS DEMASIADO RÁPIDO":
  El servidor limita a 5 mensajes cada 5 segundos para evitar spam.
- SE SIGUEN OYENDO PALMADAS O GOLPES:
  Es una limitación del filtro de ruido (RNNoise): reduce los ruidos fuertes y
  cortos, pero no los elimina del todo.
